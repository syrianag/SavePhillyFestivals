Audience: Client operations, producers, and editorial staff

Application timezone: America/New_York

Public Discovery Producer Submission Editorial Workflow Schedule + Calendar Export
This guide reflects the current implemented behavior. Some external integrations are intentionally disabled and require explicit activation before launch.

1) Fast Orientation

Visitor paths

  • Browse and filter festivals on the home page.
  • Read festival details and official links.
  • Save festivals or events in local browser schedule.
  • Email schedule and export to calendar file.

Team paths

  • Producers submit private festival drafts.
  • Editors review states and approve or request changes.
  • Admins manage user roles and account access.
  • Moderators approve or suppress social posts.

3) Visitor Workflow

Search and discovery

  • Filters are URL-backed, so search state is bookmarkable and shareable.
  • Date matching uses overlap logic for multi-day festivals.
  • If no data matches, users receive a clear reset path.

Festival details

  • Only published festivals are public.
  • Missing optional content shows user-friendly fallback text.
  • Canceled festivals show a public tombstone page with disabled action controls.

Schedule builder

  • Schedule data is stored only in the active browser and device.
  • Email and consent choices are not stored in browser local storage.
  • Overlap alerts are warnings only and do not delete selections.

Email schedule and export calendar

  • Email sends are transactional and idempotent.
  • Only currently published items are included at send/export time.
  • Calendar export creates a snapshot ICS file for Google, Apple, and Outlook.
  • All-day calendar entries use standards-based exclusive end dates.
Visitor saved schedule data remains intact even when delivery fails or unavailable items are omitted.

4) Producer Workflow

  1. Producer signs in and starts a new draft.
  2. Producer completes required fields and saves draft privately.
  3. Producer reviews acknowledgments and submits for editorial review.
  4. If changes are requested, producer revises and resubmits.
StateMeaning for producer
DraftEditable private work in progress
Pending reviewRead-only while editorial team reviews
Changes requestedEditable again with producer-safe feedback
RejectedNot accepted in current review cycle
Image upload capability is intentionally disabled until malware scanning and storage controls are fully activated.

5) Editorial and Admin Workflow

Core rule

Approval is not publication. Editors must complete a second action to publish approved content.

StatePublic visibilityTypical next action
Pending reviewNoRequest changes, reject, or approve
ApprovedNoPublish when ready
PublishedYesUnpublish or cancel if needed
CanceledTombstone onlyArchive

Moderation safeguards

  • External posts are pending by default and require explicit approval.
  • Reject and hide actions require moderator reason logging.
  • Public page render remains first-party and script-safe.
